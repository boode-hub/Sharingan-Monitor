# Sharingan Tray Monitor - Classic

The original build, kept as it was before the V1 work. Eighteen hand-drawn
eyes, a CPU/RAM switch, thresholds, colour, speed presets, shuffle and glow.

Run `Sharingan.ps1` (right-click, Run with PowerShell), or `install-startup.bat`
to start it at login. The newer build is in `..\V1`.
